# 📸 Instagram Login Page

A simple and responsive **Instagram Login Page UI Clone** built using **HTML, CSS, and JavaScript**.

This project recreates the visual structure and user experience of an Instagram-style login interface. It was developed as a frontend practice project to improve skills in webpage structure, styling, layout design, and JavaScript-based interactions.

> ⚠️ **Disclaimer:** This project is created for educational and frontend practice purposes only. It is not affiliated with, endorsed by, or connected to Instagram or Meta.

---

## 📌 Project Overview

The **Instagram Login Page** is a frontend recreation of a modern social-media login interface.

The project focuses on creating a clean and responsive authentication screen with an Instagram-inspired design. It demonstrates how HTML can be used to structure a webpage, CSS can recreate the visual design, and JavaScript can add interactive functionality.

The main purpose of this project is to practice **frontend development fundamentals** while recreating a familiar real-world interface.
